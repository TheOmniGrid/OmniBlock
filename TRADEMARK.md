# Branding and trademark policy

The OmniBlock **software** is free software under the GPL. The OmniBlock
**name and identity** are not, and this page explains where the line falls.

If you only want to use OmniBlock, none of this applies to you. This is for
people who redistribute, fork, or write about it.

## What is claimed

- The names **OmniBlock** and **OmniVex**
- The OmniBlock shield mark and application icon
- The OmniVex visual identity: the tile-icon treatment, the accent-gradient
  system, and the associated wordmarks

These are the project's marks. They are not covered by the GPL, which licenses
copyright in the code and says nothing about names or logos.

## What you may do without asking

- **Use the software.** Obviously.
- **Say what it is.** Referring to OmniBlock by name to talk about it, review it,
  compare it, write documentation, or explain that your tool interoperates with
  it is ordinary descriptive use. No permission needed.
- **Redistribute an unmodified build**, with its branding intact and its licence
  and notices included.
- **Fork the code** and do anything the GPL permits with it — under a different
  name.
- **Link to the project**, quote from this repository, and use the icon when
  illustrating an article about OmniBlock.

## What requires a different name

If you **modify** OmniBlock and distribute the result, please give it your own
name and your own icon.

This is the entire substance of the policy. It is not about controlling the
code — the GPL already guarantees you can change and share it. It is about the
name continuing to mean one specific thing, so that:

- a user who has a problem with "OmniBlock" is talking about the build this
  project shipped;
- a security claim made about OmniBlock can actually be verified against
  OmniBlock;
- a modified build cannot be mistaken for the original, in either direction.

Rename the fork, drop the shield icon, and everything else the GPL grants you is
untouched.

## What is not allowed

- Presenting a modified build as if it were the official one.
- Using the marks in a way that suggests endorsement, affiliation, or official
  status that does not exist.
- Using the marks for a different product, or registering them, or registering
  names or domains confusingly similar to them.
- Selling merchandise carrying the marks.

## Precedent

This arrangement is standard for GPL projects with an identity worth protecting.
Mozilla applies it to Firefox — which is why Debian shipped the same browser for
years under the name Iceweasel. The code was free the whole time; the name was
not.

## Questions

If you are unsure whether something is fine, ask before you ship it. The answer
is usually yes, and asking costs you an email.
